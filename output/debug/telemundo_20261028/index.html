What calculates the score?

token IDs -> embeddings + positions -> 12 contextual transformer layers -> first-position vector -> dense -> tanh -> output linear layer -> 3 logits -> softmax -> argmax

Tokenization only converts text to IDs. Learned neural layers calculate context-dependent vectors. The classifier head converts one vector into three raw scores (logits). Softmax turns those into numbers that sum to one. The largest wins.

h = final_hidden_state[first_position]
a = tanh(W_dense @ h + b_dense)
logits = W_output @ a + b_output
p[i] = exp(logit[i] - max(logits)) / sum(exp(logits - max(logits)))
