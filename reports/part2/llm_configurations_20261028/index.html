What changed?

Prompt: exact date, negation, entity and relationship checks, with three fictional examples.

Retrieval: keep the longest exact leading subject-page match among candidate pages, then rank sentences with BM25 plus a fixed anchor-page bonus. No annotations are read by the retriever.

Fallback: only when Llama answers NEI, accept a SUPPORTS/REFUTES claim-only prediction if its softmax is at least 0.80. That threshold is a fixed rule, not verified truth confidence. The final hybrid label may differ from the raw LLM response.

Reproducibility and limits

  • Exploratory 60-calibration/120-assessment study; small samples and one generation per claim.
  • Fresh LLM assessment subset is disjoint from the earlier LLM pilot, but official development has previously been evaluated with RoBERTa. It is not a blind official test.
  • Entity retrieval changes candidate inclusion and sentence ranking together; it does not isolate only one retrieval subcomponent.
  • Prompt variant adds explicit comparison rules and fictional examples together; no individual clause is isolated.
  • Hybrid E can improve labels without improving annotated evidence; report strict FEVER alongside label accuracy.
  • All response failures remain INVALID in the full denominator. Model-generated explanations are not internal reasoning traces.
  • No model retraining, default changes, new downloads or paid API requests. Existing results are preserved.

Raw calls, sample IDs, source hashes, frozen selection, and all results are retained in the experiment directory. Original defaults and results remain unchanged.

FEVER supplied the claims and human labels. Experiment code and viewer added with AI assistance. Local page, accessible on this computer.

Paired uncertainty on the assessment sample

Macro-F1 difference, 95% interval: -0.0107 to +0.1809.

Strict FEVER difference: +4.17 percentage points; 95% interval: -5.83 to +14.17 points.

Paired resampling of claims with predictions fixed, not a generation or training repeat. Exploratory intervals without multiplicity adjustment.

How much did the fallback contribute?

The selected hybrid’s raw LLM component scored 57.50% accuracy. The fixed fallback changed 4 labels: 3 errors fixed and 1 introduced.

This audits a component of the preselected hybrid using existing responses. It does not change the selection or create another chosen model after seeing assessment results.
